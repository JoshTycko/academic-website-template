# Hosted paper PDFs

Put clean, main-text PDFs here (no highlights, annotations, or supplements) and
point the "PDF" links on `publications.html` at them.

**Naming:** `<kebab-title-slug>-<year>.pdf`, for example
`compact-gene-switches-2024.pdf`. Lowercase, no spaces.

**What's safe to host:** open-access papers (CC-BY journals, bioRxiv/arXiv
preprints) are freely licensed, so you can host the publisher PDF. For
subscription journals, check the journal's self-archiving policy (Sherpa Romeo,
<https://openpolicyfinder.jisc.ac.uk>); usually you may post your accepted
manuscript but not the typeset publisher PDF. That call is yours as the author.

Until a PDF is here, link the free full text on PubMed Central or the preprint
server instead.

GitHub warns about files over 50 MB and rejects files over 100 MB. Link large
files (a dissertation, say) from your university repository rather than hosting
them here.
